# Code of conduct

## The short version

Be kind, be patient, and assume the other person is acting in good faith. That
covers almost everything.

## What is expected

Treat everyone with respect regardless of experience, background or identity.
Disagree about ideas freely — code review is supposed to be direct — but keep it
about the work rather than the person. Accept feedback gracefully, and give it
the way you would want to receive it. If you are new here, ask; nobody was born
knowing how WebRTC renegotiation works.

## What is not acceptable

Harassment of any kind, personal or political attacks, sexualised language or
imagery, publishing someone's private information, or sustained disruption of
discussions.

## Scope

This applies in issues, pull requests, commit messages and any other project
space, and to anyone representing the project publicly.

## Enforcement

Report a problem to the maintainer through
[GitHub](https://github.com/Ahsan-muhd-444). Reports are handled privately.
Depending on severity, the response ranges from a private word to a permanent
ban from the project. The maintainer's decision is final.
